# Changelog

All notable Garden Manager changes are recorded here. Versions follow semantic
versioning.

## [1.0.0] - 2026-07-24

### Added

- Local-first garden operations workspace with Docker Compose deployment.
- Editable gardens, plots, plantings, individual plants, tasks, observations,
  media links, schedules, assets, tools, growing factors, inventory, harvests,
  market prices, alerts, notification endpoints, and related records.
- Non-geographic 2D garden map with editable geometry, elevation points,
  interpolated contours, and ideal hydraulic-head estimates.
- Scientific-name autocomplete, plant requirements, expected yield and harvest
  tracking, qualitative and instrument readings, and deficiency assessments.
- Automatic event triage with Web Push, SMTP email, and speaker-webhook
  delivery adapters.
- Prisma migration history, seed data, tests, production builds, and local
  deployment documentation.
